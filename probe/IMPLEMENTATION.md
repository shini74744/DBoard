## 已实现

- 系统管理新增“探针管理”，可进入真实哪吒后台、配置接入、选择服务器更新连接地址。
- 启用后，添加服务器会创建哪吒服务器身份，生成探针地址上的安装命令。
- 单个整合 Agent 同时运行哪吒监控和现有节点引擎，支持 Linux amd64/arm64。
- 节点管理 API、WebSocket、监控 gRPC、安装与升级下载均使用探针入口。
- 面板连接服务主动连接探针；探针不保存面板地址和原机器 Token。
- 保留现有按用户分流、前置认证、负载均衡、连接数限制和出口统计。
- 后台域名迁移：选择服务器、校验目标、持久保存、自动重连、离线任务、备用地址和迁移状态。
- 面板连接服务也支持备用地址；旧域名失效时可从后台验证并设置可用的新入口。
- 流量报告持久化、增量计费去重；失效节点的异常批次隔离，避免阻塞其他节点报告。
- 整合 Agent 有独立的版本来源，升级验证身份、校验和及连接恢复，失败恢复旧程序。

## 地址迁移边界

- 新域名和备用域名需要指向同一个探针服务；更换探针主机时还要迁移数据库、身份注册表和密钥。
- 旧域名应保留到所有目标节点完成迁移。
- 如果某节点所有已知地址均不可访问，需要先恢复其中一个地址，或在该节点本地更新配置；
  离线机器无法凭空收到一个此前不知道的新域名。
- 节点侧不配置 JC 管理地址，但拥有 root / 虚拟化宿主权限的人仍能检查程序和代理行为。
