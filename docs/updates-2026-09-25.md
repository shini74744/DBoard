# 2026-09-25 面板与用户端更新

> 本文原有条目记录当日用户端/套餐阶段的改动，下面提到的 v0.1.12 是该阶段的节点基线，不代表当前最新整合 Agent。完整系统现状请以[文档索引](README.md)、[安装指南](installation.md)和[探针记录](../probe/IMPLEMENTATION.md)为准。

## 管理后台

- 系统管理新增用户须知编辑，登录、注册和找回密码页面统一读取设置。
- 权限组支持按当前排序从 1 重新分配显示 ID，内部 ID 保持不变。
- 节点管理支持独立落地分区及分组；出口选择可展开、收起并按分组筛选。
- 节点出口新增独立累计流量，覆盖第三方出站与系统节点出口；保留全局出站累计统计。
- 路由用户选择默认展示拥有该节点有效套餐的用户，支持排除指定用户，并改善滚轮操作。
- 套餐库存展示支持原有库存状态与剩余名额两种模式。

## 用户端

- 商店展示设备限制，隐藏未设置价格的周期，保留明确配置的零元价格。
- 购买页区分新开独立套餐与续费指定同款套餐，取消单套餐替换提示。
- 原套餐卡片续费沿用该份套餐的周期价格；从商店新开或续费均使用商店标价。
- 商店续费保留原套餐的管理员专属价格，供后续从原套餐卡片续费时使用。
- 订单保存购买入口、报价及续费前到期时间；列表和详情展示操作类型、价格依据及正确金额。
- 修复加密 API 网关丢失套餐报价查询参数的问题。
- 购买方式卡片位于订单摘要下方、提交按钮上方。点击已持有套餐数量可展开名称、到期时间和流量信息。

## 部署与节点兼容性

- 面板包含 `2026_09_24_000018` 至 `2026_09_24_000022` 数据迁移；部署时正常执行 Laravel 数据迁移并刷新服务缓存。
- 用户端从 `frontend/` 执行 `npm ci`、`npm run build`，发布 `dist/`。保留站点原有 `runtime-config.js`，不要用开发环境配置覆盖。
- 本次未更改节点 Go 源码，现有 **v0.1.12** 二进制支持所需用户路由及出口流量上报。
- 排除用户规则由后台展开为现有节点支持的用户匹配规则；分项流量使用已有上报数据累计。
- 仓库内 DUI / xboard 兼容名称二进制及 SHA256SUMS 已与现有 v0.1.12 Release 对齐。本次无需新节点版本或节点重启。

## 同日后续：整合探针与管理入口

- 已发布整合 Agent v0.2.1；节点管理、监控及程序下载使用探针入口。

- main 的后台修复不等于 v0.2.1 Release 附件已经更新；当前服务端构建方法见安装指南。
- 新增用户指南、后台流程、逐步安装与备份运维文档。
