# 用户端使用指南

适用范围：本仓库的 DBoard 用户端 frontend/，与支持多套餐的面板配套使用。本文对应 2026-09-25 main 源码；运营者可以关闭部分入口或调整文字。

相关文档：[后台处理流程](admin-workflows.md) · [完整安装步骤](installation.md) · [升级与排错](operations.md)

## 1. 从注册到使用

1. 打开运营者提供的用户网站，注册或登录账号。
2. 阅读用户须知；若设置了等待时间，倒计时结束后才能关闭。
3. 进入商店，查看套餐流量、设备限制、可购买周期、价格和库存提示。
4. 点击购买，选择计费周期，确认购买方式和订单金额。
5. 完成支付；免费订单也需要提交并完成结算流程。
6. 回到首页，在对应套餐卡片查看到期时间和可用流量。
7. 点击该卡片的「导入订阅」，按客户端提示导入；持有多份套餐时，也可使用「合并订阅」。
8. 在代理客户端更新订阅并选择可用节点。网页登录成功不代表代理客户端已经连接。

~~~mermaid
flowchart LR
  A[注册或登录] --> B[商店选择套餐]
  B --> C[选择周期和购买方式]
  C --> D[确认报价并提交]
  D --> E[支付与后台处理]
  E --> F[套餐卡片生效]
  F --> G[导入或更新订阅]
  G --> H[客户端连接节点]
~~~

## 2. 新开和续费有什么区别

| 操作入口 | 选择 | 结果 | 价格依据 |
| --- | --- | --- | --- |
| 商店 | 新开一份 | 新增独立套餐，可与已有套餐同时使用 | 当前商店标价 |
| 商店 | 续费同款 | 选择自己持有的某一份同款套餐进行续费 | 当前商店标价 |
| 首页某一份套餐卡片 | 续费套餐 | 续费这份指定套餐 | 这份套餐的专属周期价格；没有专属价格的周期使用标准价格 |

例如：商店月付 40 元，管理员给某份已持有套餐设置月付续费价 35 元：

- 从原套餐卡片续费月付，报价为 35 元。
- 从商店新开同款，报价为 40 元。
- 从商店选择同款续费，当前订单报价也为 40 元。
- 商店续费不会抹掉原套餐保存的专属价格；以后从原卡片续费仍可使用该周期专属价格。
- 优惠券、折扣、余额抵扣会进一步影响最终应付金额，以订单摘要为准。

周期套餐续费通常在尚未到期的时间上延长；已到期则从当前时间开始计算。流量额度、限速、设备限制以及重置行为还受套餐配置和开通事件影响，不能把「续费」理解成只改日期、其余字段永远不变。

### 持有多份同款时

1. 在购买页选择「续费同款」。
2. 选择要续费的具体套餐，核对到期时间和已有流量信息。
3. 不持有同款时，续费同款选项不可用，应选择新开。
4. 点击「已持有 N 份套餐」可展开查看持有情况。
5. 购买方式卡片位于订单摘要下方、结账按钮上方，提交前再核对一次目标。

新开不会自动替换其他套餐。不要仅根据套餐名称判断续费目标；同名的多份套餐可以有不同到期时间和专属价格。

## 3. 价格、周期与库存

### 没有填写的价格

- 未配置价格的周期不会出现在可购买周期中。
- 明确填写的 0 元与留空不同：0 元可以作为免费价格显示，留空表示未提供。
- 流量包与重置包的模板行，在对应价格没有填写时不显示。
- 没有可购买周期或后台判定无法购买时，不能继续下单。

### 库存的两种展示

运营者可选择：

- **状态展示**：库存充足、余量提示或售罄等标签。
- **剩余名额展示**：直接显示剩余名额；没有容量上限时显示不限量。

状态标签是展示提示，最终是否允许购买仍由后台判断。新开一份和续费已有套餐的容量校验不同，因此不要把某个颜色标签当成购买成功的保证。

## 4. 流量包与重置包

| 类型 | 含义 | 使用条件 |
| --- | --- | --- |
| 一次性流量包 | 对应一次性套餐，不设置周期到期时间 | 该价格已配置，且后台允许购买 |
| 重置包 | 对选定的当前套餐执行流量重置 | 持有有效的对应套餐，且该价格已配置 |

重置包不等于新开套餐，也不自动延长有效期。已过期或没有对应有效套餐时，后台会拒绝重置购买。

## 5. 订单列表怎么看

订单列表和详情可用于核对：

- 套餐名称、订单号、创建时间和计费周期。
- 新开、续费等操作类型，以及续费目标。
- 商店标价或原套餐价格等价格依据。
- 报价、优惠、余额抵扣及最终应付金额。
- 待支付、处理中、已完成、已取消等状态。

管理员手动调整套餐产生的记录与实际付款订单含义不同。用户可见的调整记录聚焦周期、流量、续费价格等信息，不把连接数或倍率的内部调整展示为套餐变更通知。

已完成订单不能作为待支付订单再次支付。支付后未立即看到套餐变化时，先查看订单状态，再刷新套餐卡片；仍异常时提供订单号给客服，避免重复购买。

## 6. 套餐卡片、订阅与节点列表

- 每份套餐有自己的有效期、额度和使用情况。
- 导入某张卡片的订阅前，确认选中了正确的套餐。
- 合并订阅用于统一获取可用节点，不代表把多份套餐的计费身份、价格或额度合成一份。
- 更新了权限组、节点或套餐后，需要在客户端刷新订阅。
- 设备限制与连接数限制是两个不同字段，不要把一个 TCP/UDP 连接当成一台设备。
- 节点卡片显示的倍率属于展示信息；实际扣量由后台计费配置计算，有疑问时核对流量明细与运营者说明。

## 7. 用户请求走哪条链路

### 网页、订单和订阅管理

启用 DUI-Gateway 时：

用户浏览器 → HTTPS 用户 API 网关 → DBoard 后端 → 返回套餐、订单或订阅数据。

未启用 DUI-Gateway 时，用户端直接使用配置的面板 API 或同站反向代理。

### 实际代理流量

代理客户端 → 订阅中的入口节点 → 节点路由选择的出口或落地 → 目标网站。

代理流量不经过探针监控后台，也不经过 DUI 的网页 API 加密层。普通用户不需要登录探针后台。

## 8. 常见问题

| 现象 | 先检查什么 |
| --- | --- |
| 提示价格尚未确认 | 重新选择周期；仍失败时由管理员核对报价接口和网关查询参数，不能按页面上的 0 元强行提交 |
| 持有多份套餐却不知道续费哪一份 | 从目标套餐卡片进入续费，或展开持有套餐列表核对 |
| 想使用管理员专属续费价 | 从原套餐卡片续费，不从商店重新下单 |
| 已支付但套餐未生效 | 查看订单状态，等待后台处理；异常时提供订单号 |
| 看不到某个节点 | 检查套餐有效期、剩余流量、权限组、节点是否公开及客户端订阅是否刷新 |
| 网页可登录但客户端无法连接 | 网页 API 和代理端口是不同链路，检查节点连接及客户端配置 |
| 流量重置没有延长日期 | 重置包只重置流量，不负责延长有效期 |
